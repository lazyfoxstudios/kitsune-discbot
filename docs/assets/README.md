# Kitsune artwork

- `kitsune-icon.png`: existing purple Kitsune OS application icon.
- `kitsune-blink.gif`: the clean blinking portrait supplied for this website. The original filename was `Kitsune-Blink-Cropped.gif`; the website uses the complete supplied image, preserving both ears and the original animation. The image is not placed inside a clipping mask.

Both files are copied byte for byte. No placeholder or newly generated branding is used. The website's pause control draws the visible GIF frame to a same-size canvas; reduced-motion preference starts with a still frame when JavaScript is enabled. Without JavaScript, the original GIF remains visible and animated.

These assets are project branding, not an open-source asset pack. Rights remain with their respective owners.
